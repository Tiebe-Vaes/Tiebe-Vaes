# Hi, I'm Tiebe

I'm a software development student who builds full-stack web apps, mostly with TypeScript, React/Next.js and Java/Spring Boot. I like work that ends up in front of real users: client projects, team projects and the occasional hackathon.

## Projects

### GO!SmartLib

*Next.js, Spring Boot, MySQL, Docker*

Library management system for the secondary schools of GO! Scholengroep Antwerpen, built with a team of four. I worked on the gamification (XP, badges, leaderboards), reading lists and announcements, in both frontend and backend. The code lives on the school GitLab.

### [Travel planning architecture](https://github.com/Tiebe-Vaes/travel-planning-architecture)

*Node.js, PostgreSQL, Redis, RabbitMQ, Docker Swarm*

Architecture case study for a group travel platform: six ADRs, a C4 model and five proofs of concept that deploy to Docker Swarm. I wrote the authentication ADR and built the OAuth2 + JWT login POC. Team of five.

### [Ripple](https://github.com/dylanhavelaerts/Tectonic-Hackaton)

*Next.js, TypeScript*

Built at the Tectonic Hackathon 2026 for the SD Worx case. It scores company documents that contradict each other, shows why a source can be trusted and sends open questions to the right expert.

### [LocalLend](https://github.com/Tiebe-Vaes/LocalLend)

*Flutter, Riverpod, Firebase*

Peer-to-peer rental app for tools and household appliances, with maps, a booking calendar and real-time sync between clients. Built in a team of two.

### [Kart race app](https://github.com/Tiebe-Vaes/kart-race-app)

*React Native, Expo, Firebase*

Mobile app where kart racers browse tracks, organise races, reserve a spot and chat per race. Built in a team of two.

### [PetalPurrs](https://github.com/Tiebe-Vaes/PetalPurrs)

*React*

A cozy tea-shop browser game where you brew orders for cat customers.
